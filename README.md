# 🍣 Enot Sushi — Сервіс доставки їжі

Сучасний, швидкий та оптимізований вебдодаток для ресторану доставки (суші, піца, бургери), створений за допомогою **Next.js 16** (App Router) та **Supabase**.

## 🚀 Технологічний стек

- **Фреймворк:** Next.js 16 (React 19)
- **Стилізація:** Tailwind CSS + кастомні CSS анімації
- **База даних:** Supabase (PostgreSQL)
- **Мова:** TypeScript
- **Деплой:** Google Cloud Run (Docker) / Vercel
- **Оптимізація зображень:** Sharp

## ✨ Основні можливості

- **Динамічне меню:** Всі страви та категорії завантажуються з бази даних Supabase.
- **Кошик:** Зручний кошик із підрахунком загальної суми та збереженням стану (Context API).
- **Оформлення замовлення:** Інтеграція з платіжними системами (LiqPay, Monobank).
- **Адмін-панель:** Вбудована панель керування (`/admin`) для редагування меню, перегляду замовлень та налаштування контактних даних сайту.
- **Безпека:** Адмін-панель захищена повноцінною системою авторизації **Supabase Auth** (Role-Based Access Control) на рівні серверного Middleware.
- **SEO-оптимізація:**
  - Динамічні мета-теги та OpenGraph зображення для кожного товару.
  - Автоматична генерація `sitemap.xml` та `robots.txt`.
  - Вбудована мікророзмітка Schema.org (LocalBusiness).
  - Ідеальна швидкість завантаження (100/100 Lighthouse).

## 🛠 Локальний запуск (Розробка)

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Quiincy/takasho.git
   cd takasho
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Створіть файл `.env.local` у корені проєкту та додайте ваші ключі:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=ваша_адреса_supabase
   NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_key_supabase
   ```

4. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
   Додаток буде доступний за адресою [http://localhost:3000](http://localhost:3000).

## ☁️ Деплой на Google Cloud Run

Цей проєкт налаштований для легкого розгортання в Docker-контейнерах на Google Cloud Platform.

1. У проєкті вже є `Dockerfile`, `next.config.ts` (standalone mode) та `.dockerignore`.
2. В панелі Google Cloud Run виберіть "Continuously deploy from a repository".
3. Підключіть цей репозиторій.
4. Додайте змінні оточення (без `NEXT_PUBLIC_` префіксу для runtime):
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
5. Натисніть **Deploy**.

## 🗄 Структура Бази Даних (Supabase)

Проєкт використовує наступні таблиці:
- `menu_categories` — Категорії меню (Суші, Піца тощо).
- `menu_items` — Самі страви (з цінами, описом, фото та прив'язкою до категорій).
- `site_settings` — Контактні дані сайту (телефон, адреса, графік роботи, email).
- `orders` — Збережені замовлення клієнтів.
